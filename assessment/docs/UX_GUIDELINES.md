# UX Guidelines for the New Interview

## Main Rule
The UI should feel like a smart assessment flow, not a generic chatbot.

## UX Principles

1. Each screen should have one clear objective
2. Prefer quick selection inputs before text
3. Group related questions in one card
4. Keep candidate typing effort low
5. Show progress without exposing too much complexity
6. Keep transitions fast and smooth
7. Preserve seriousness and professionalism

## Recommended Question Mix

Use more:
- radio buttons
- checkboxes
- dropdowns
- short text fields
- numeric fields

Use less:
- long essay fields
- open chat style input
- repeated confirmations

## Best Card Patterns

### Pattern A — Single Decision
One radio question with 3–5 options.

### Pattern B — Compact Profile Card
Three short related fields:
- status
- city
- availability

### Pattern C — Skills Evidence Card
- years of experience
- tools used
- one short project proof text

### Pattern D — Motivation Card
- primary reason
- preferred environment
- one short explanation

## Loading Experience

- disable submit button during request
- show light progress state immediately
- stream or skeleton-render next card
- never leave user without feedback

## Validation Rules

- required fields validated client-side
- keep labels simple
- keep placeholders concrete
- avoid giant forms

## Important
A candidate should feel:
- guided
- respected
- not overwhelmed
- not forced to write too much
